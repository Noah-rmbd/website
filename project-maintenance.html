M/ai/ntenance: Predictive maintenance GUI for Renewable Energy Systems

An intuitive and adaptable application for doing supervised Machine Learning for fault detection in Renewable Energy Systems.

// TIMELINE Q1 2024 (3 Mos)
// ROLE Student project
// STACK Python, PyQt6, Scikit-Learn, NumPy, Pandas
// STATUS Ended
M/ai/ntenance

01 Project Overview & Challenge

As renewable energy infrastructures expand, transitioning from curative repairs to predictive maintenance is essential to lower operational costs, minimize downtime, and optimize power generation. In collaboration with Louis Arnaud and supervised by doctoral researcher Bassel Chokr and Dr. Nizar Chatti at the LARIS laboratory (Polytech Angers), we designed and implemented M/ai/ntenance—a generic desktop application engineered to streamline the fault diagnosis pipeline for photovoltaic systems and industrial equipment. The software bridges the gap between academic machine learning research and practical application, providing non-expert operators with an end-to-end, guided graphical interface to process raw measurement datasets, extract critical features, train supervised classification models, and benchmark performance metrics.

"This project was my first experience with the machine learning domain, thanks to the support of Nizar Chatti and Bassel Chokr, it was an excellent opportunity to learn the basics."

02 Architecture & Technical Implementation

The application guides the user step-by-step through a modular machine learning pipeline:

  • >

    Data Ingestion & Visual Exploration

    Supports drag-and-drop loading for CSV, XLSX, and Parquet data formats. Users can inspect tabular data, compute descriptive statistics (mean, standard deviation), and generate interactive exploratory plots—including correlation heatmaps, box plots, histograms, and scatter plots.

  • >

    Data Preprocessing

    Offers integrated tools for manual feature removal, dataset splitting into customizable train/test proportions, and scaling transformations (Min-Max normalization and standard score standardization).

  • >

    Dimensionality Reduction and Feature Selection

    Employs an Information Gain (entropy-based) ranking engine with interactive threshold filtering, as well as Principal Component Analysis (PCA) to eliminate redundant signals, optimize training times, and mitigate overfitting.

  • >

    Multi-Model Training Suite

    Integrates four supervised classification algorithms via Scikit-Learn: Decision Trees (CART), K-Nearest Neighbors (KNN), Random Forest, and Multi-layer Perceptron (MLP), complete with tunable hyperparameters.

  • >

    Model Evaluation and Export

    Features a comparative dashboard displaying training and inference runtimes, multi-class confusion matrices, and detailed performance scores (Accuracy, Precision, Recall, and F1-score). Retained models can be exported directly as serialized .pkl binaries or documented Python .txt deployment scripts.
