Startux: A 3D spatial game

A student project that turned into a 3D space rail shooter in C++ and OpenGL

// TIMELINE Q1 2025 (3 Mos)
// ROLE Student project
// STACK C++11, OpenGL, CMake, OpenAL, FreeType
// STATUS Ended
Startux

01 Project Overview & Challenge

Developed in collaboration with François Balmadier and Maël Tallard for a Computer Graphics course, StarTux is an arcade-style 3D space navigation game built from scratch using C++ and modern OpenGL. Players pilot a spaceship through dangerous cosmic environments, evading randomly spawned asteroid fields, collecting score rings, and clearing flight paths using projectile weaponry. The project emphasizes low-level graphics engineering, combining a custom component-based engine architecture, a hierarchical scene graph, real-time lighting, particle systems, and dedicated developer tooling.

02 Engine & Scene Graph Architecture

  • >

    Hierarchical Scene Graph

    Organizes 3D spatial entities through transformation nodes (scene_root and world_node), enabling clean parent-child coordinate transformations and independent motion across gameplay objects.

  • >

    Viewer & Event Loop

    Uses GLFW to manage cross-platform window initialization, poll keyboard/mouse input events, and maintain a stable 30 FPS rendering loop.

  • >

    Modular Engine Design

    Separates runtime systems into specialized components, decoupling game logic, interface management, geometry rendering, and audio processing.

  • >

    Audio Pipeline

    Integrates an OpenAL-based AudioManager using libsndfile to drive multi-channel background music and synchronized 3D sound effects for weapon fire and collisions.

03 Gameplay Systems & Developer Tools

  • >

    Flight & Dual-Weapon Combat

    Implements responsive ship navigation with roll control alongside two distinct projectile systems: high-rate-of-fire light energy bolts and heavy ordnance.

  • >

    Collision detection & Optimization

    Features bounding-volume collision checking accelerated by spatial partitioning techniques to handle dense entity fields efficiently.

  • >

    Dual Runtime Modes

    Includes a standard play mode for arcade gameplay and a developer mode featuring a free-flying debug camera, real-time performance profiling, and toggleable collision visualization spheres.

  • >

    Progression Mechanics

    Tracks player performance via an arcade scoring system incorporating ring collections, survival bonuses, speed multipliers, and daily challenge objectives.
