💾 Project // 01

Automating Geospatial Trajectory Plausibility Analysis with Machine Learning

A research internship project within the AVIZ team of the LISN/INRIA lab

// TIMELINE Q2 2026 (4.5 Mos)
// ROLE Research Internship
// STACK Python, JS, SQL, Scikit-Learn, NumPy, Pandas
// STATUS Ended
Interactive Trajectory Visualization

01 Project Overview & Challenge

Open crowdsourced geospatial platforms, such as iNaturalist and Gowalla, offer rich spatiotemporal records but lack standardized capture protocols, making them susceptible to GPS spoofing, hardware glitches, and user reporting biases. Building upon the visual Motion Plausibility Profile (MPP) framework, this project automated the evaluation of contributor movement plausibility by engineering a comprehensive machine learning and trajectory anomaly detection pipeline.

"This internship gave me a look to what research is about: taking time to read about the topic, always take notes about the results, and seek for new solutions when we reach a technological impasse"

02 Interactive Visualization Platform

To bridge the gap between machine learning metrics and visual interpretation, I built an interactive exploration platform:

  • >

    Full-Stack Mapping Interface

    Developed a web application using JavaScript, Leaflet, and Plotly backed by Python and an optimized SQL database to query and render multi-million-point spatiotemporal datasets.

  • >

    Dynamic Bubble Clustering

    Implemented hierarchical spatial aggregation to dynamically cluster dense trajectory clusters across global views, expanding into granular paths upon inspection.

  • >

    Kinematic & Anomaly Rendering

    Integrated customized speed-scale color encodings, trajectory timeline filters, and dashed styling to visually highlight suspicious transitions directly on OpenStreetMap.

03 Machine Learning Pipeline & Benchmarking

To identify varied error profiles without relying on pre-existing ground truth labels, I engineered an end-to-end evaluation framework:

  • >

    Dual-Scale Feature Engineering

    Extracted transition-level kinematic vectors (geodesic distance, elapsed time, speed, sine/cosine transformed bearing changes) for sequential analysis, alongside global trajectory descriptors (path efficiency, turning entropy, radius of gyration, direction reversal frequency) to capture structural patterns.

  • >

    Synthetic Anomaly Injection Benchmark

    Built an automated anomaly simulator generating distinct error profiles—including abnormal speed sequences, erratic back-and-forth oscillations, and hardware timestamp bugs—to evaluate unsupervised detectors against curated baselines.

  • >

    Model Implementation & Comparison

    Evaluated deep sequential architectures (standard LSTM Autoencoders, Time-Aware LSTMs, and an LSTM Forecaster that delivered a 14% AUC improvement and resolved trajectory length bias) against classical models (Isolation Forest, One-Class SVM).

04 Key Research Findings

The experimental evaluation demonstrated that purely unsupervised sequential deep learning architectures struggle with crowdsourced geospatial traces due to extreme data sparsity, as valid trajectories in these platforms average only three transitions. While global geometric features excelled at detecting structural anomalies like back-and-forth movements, kinematic errors were best isolated at the transition level. Consequently, the research concluded that the most robust production architecture is a hybrid system: pairing deterministic physical rules to filter impossible kinematics with contextual machine learning models to detect complex structural outliers.
